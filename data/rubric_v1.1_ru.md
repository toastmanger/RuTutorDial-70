# Критерии для разметки (редакция v1.1 — после сверки)

Вердикты: `1` соблюдён / `0` нарушен / `NA` неприменим (в основном C5).

## C1 — математическая корректность реплик учителя

**1:** все математические утверждения учителя верны: вычисления, преобразования, вердикты о шагах ученика (не подтверждает неверное, не отвергает верное).
**0:** хотя бы одно ложное мат-утверждение или неверный вердикт о шаге ученика.
**Не нарушение:** намеренно неполные подсказки; риторический вопрос с заведомо неверной альтернативой при ясном педагогическом приёме.

## C2 — нет преждевременного раскрытия решения

**0:** учитель сообщает итоговый ответ или выдаёт готовый шаг (формула с подставленными числами / результат вычисления) до **2 неудачных попыток ученика именно на этом шаге**.
Правила счёта попыток: попытки считаются **отдельно для каждого шага**; попыткой считается только попытка **с уже установленными входными данными** шага; **повтор уже установленного значения** (как вход следующего шага) — не новое раскрытие.
**Не нарушение:** раскрытие после ≥2 неудачных попыток на шаге; подтверждение верного шага ученика; проговаривание ответа в финале, когда ученик уже дошёл.

## C3 — адресация заблуждения ученика

**1 — только если учитель ЯВНО связывает разбор с ошибочным отношением, операцией или допущением исходного решения** (локализует ошибку и разбирает, почему это ошибка).
**0, в том числе когда:** учитель ведёт по новому решению с нуля, не разбирая ошибочный элемент; выдаёт недостающий шаг без объяснения связи с исходной ошибкой; ученик исправляет исходную ошибку сам, а учитель разбирает только другое (самоисправление учителю не засчитывается).
**Не нарушение:** короткий откат к базовому шагу при вскрывшемся более глубоком пробеле; переход дальше после разбора заблуждения.

## C4 — посильность scaffolding

**Реплика-нарушение** = реплика учителя, которая подставляет неустановленный промежуточный результат, перепрыгивает текущий шаг, задаёт вопрос без материала для ответа, либо сваливает несколько вопросов без ожидания ответа.
**0:** в диалоге ≥2 реплик-нарушений.
Критерии независимы: одна реплика может нарушать C1 и C4 одновременно, но нарушение C1 само по себе не делает её репликой-нарушением C4.
**Не нарушение:** единичный крупный шаг, скорректированный после затруднения ученика.

## C5 — верность финального вердикта

Применим, только если учитель в конце фиксирует статус («всё верно!», «разобрались»).
**1:** статус соответствует действительности (сверь финальный результат ученика с верным ответом).
**0:** противоречит. **NA:** финального статуса нет.
